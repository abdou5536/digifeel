# Digifeel : installer l'application (guide à envoyer au restaurant)

Adresse du logiciel : **https://digifeel.vercel.app/login**
Vos identifiants (e-mail + lien pour choisir votre mot de passe) vous ont été envoyés par Digifeel.

## 1. Première connexion
1. Ouvrez le lien d'invitation reçu par e-mail (vérifiez les spams).
2. Choisissez votre mot de passe (8 caractères minimum).
3. Vous arrivez dans votre espace. Mot de passe oublié ? Sur la page de connexion, cliquez sur « Mot de passe oublié ? ».

## 2. Installer comme une application (sans rien télécharger)
- **Tablette / téléphone Android (Chrome)** : menu ⋮ → « Installer l'application » (ou « Ajouter à l'écran d'accueil »).
- **iPhone / iPad (Safari)** : bouton Partager → « Sur l'écran d'accueil ».
- **PC (Chrome ou Edge)** : icône « Installer » à droite de la barre d'adresse, ou menu → « Installer Digifeel ».

## 3. Installer sur Windows (version PC)
Digifeel vous envoie `Digifeel-Setup-x.y.z.exe`. Double-cliquez, suivez l'assistant, puis ouvrez « Digifeel » depuis le bureau. Si Windows affiche « Windows a protégé votre PC », cliquez « Informations complémentaires » → « Exécuter quand même ».

## 4. Mettre en route
1. **Gestion → Établissement** : vérifiez le nom, la devise et les couleurs.
2. **Menu** : ajoutez vos plats ou importez votre carte (photo/PDF).
3. **Serveurs** : créez un compte par serveur (il ne voit que la caisse et le menu).
4. **Tables** : scannez le QR collé sur chaque table et donnez-lui un nom.
5. **Imprimante** : Gestion → Imprimante pour régler le ticket.
6. Faites une vente test, puis annulez-la.

## En cas de problème
Écrivez à Digifeel avec le nom du restaurant et une capture d'écran.
